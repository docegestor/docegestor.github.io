## `> whoami`

```bash
$ cat /dev/docegestor
Nome:   DoceGestor
Preço:  grátis, sem mensalidade
Foco:   confeitaria · precificação · encomendas · resultados
Modo:   PWA instalável · offline · sem cadastro
```

App **gratuito** para quem transforma carinho em negócio. Organize receitas, **calcule preços** e acompanhe encomendas e resultados da sua confeitaria. Os dados ficam no **seu dispositivo** e você começa a usar **sem criar conta**.

---

## `> ls ./recursos`

| Recurso | Detalhes |
|---------|----------|
| 💰 **Precificação** | Some ingredientes, embalagem, mão de obra e custos fixos para saber quanto cobrar |
| 📒 **Receitas** | Fichas técnicas, rendimentos e acompanhamento do custo dos seus produtos |
| 🧁 **Encomendas** | Vendas, prazos, sinais e valores pendentes num só lugar |
| 📦 **Estoque** | Referências de compras, quantidades e custos dos insumos para planejar a próxima produção |
| 📊 **Resultados** | Vendas, despesas, metas e lucro estimado para acompanhar a evolução do negócio |
| 💾 **Backup** | Exporte um arquivo local ou configure a sua própria planilha Google para sincronizar entre aparelhos |

## `> cat ./privacidade`

```json
{
  "cadastro": false,
  "mensalidade": 0,
  "dados": "ficam no seu dispositivo",
  "offline": "depois do primeiro acesso",
  "nuvem": "opcional, a sua própria planilha Google",
  "venda_de_dados": false,
  "codigo": "disponível para consulta"
}
```

- **Sem cadastro** — abra o app e comece, os registros principais ficam no armazenamento local do navegador
- **Funciona offline** — depois do primeiro acesso, os recursos instalados do PWA podem funcionar sem internet
- **Nuvem opcional** — se conectar o Google Sheets, a cópia fica na sua planilha e na sua conta. Enviar e restaurar são ações manuais
- **Seus dados são seus** — o projeto não recebe sua lista de clientes, vendas ou receitas e não vende dados

> [!NOTE]
> Sincronização e links externos precisam de conexão com a internet.
